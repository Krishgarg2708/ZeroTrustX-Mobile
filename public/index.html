DEPLOYMENT & DISTRIBUTION

Deploy on Vercel in 60 Seconds

Host this ZeroTrustX web command center globally on Vercel while distributing the native APK to mobile devices.

▲

1. Deploy to Vercel

This repository is configured with vercel.json. You can deploy it instantly with zero configuration.

1 Push this project to a GitHub Repository.
2 Log in to Vercel.com and click Add New Project.
3 Import your GitHub repository and click Deploy. Vercel automatically deploys the public command center!
OR USING VERCEL CLI: npm i -g vercel && vercel deploy --prod
Deploy Repository to Vercel
🤖

2. Install on Mobile Phone (APK)

Install the native Android app directly onto any physical Android device or enterprise emulator.

1 In AI Studio settings, click Download Project ZIP or Generate APK.
2 Transfer the generated app-debug.apk to your Android phone via USB, Drive, or messaging.
3 Tap the APK file on your device and select Install (Allow from this source).
OR VIA ADB COMMAND LINE: adb install app/build/outputs/apk/debug/app-debug.apk
